朗读 + 高亮 + 字幕视频

真实仓库输出画面抽帧，不是新生成的营销样机。

适合什么人？

  • 老师用文本型讲义制作复习视频
  • 知识创作者将材料整理成可播放的视频
  • 培训人员需要保留原 PDF 的讲解视频

第一轮测试只验证你自己的实际材料是否可用。

你实际能得到什么？

  • 逐句语音朗读，原 PDF 逐行高亮
  • 画面大字幕；视频 MP4 输出
  • 纯音频 MP3 和字幕 SRT

不是专业分镜生成器；也不是随点随读的在线阅读器。

怎么参与内测

如果你自己确实需要把 PDF 讲义制作成视频，请从你看到介绍本项目的原平台私信作者“讲义试用”，补充三个信息：

  1. 你过去一个月实际制作过几份讲义视频？
  2. 以前怎么做、最耗费时间的步骤是什么？
  3. 你愿意用一份自己有权使用、没有隐私信息的文字型 PDF 测试吗？

如果使用 GitHub，可以通过公开反馈模板提交问题；请勿公开私密文档、联系方式或任何个人信息。

重要提示：这是招募介绍页，不提供在线 PDF 转码、支付或自动报名表单。当前公开源码只在少量文档上验证，扫描件、复杂多栏、公式等可能失败。在线语音模式会将朗读文字发送给语音服务。
