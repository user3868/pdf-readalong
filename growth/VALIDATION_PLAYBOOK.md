# PDF Readalong：首批 30 个目标用户验证

状态：**计划已准备，尚无实际招募、试用或付费数据。** 本文不把访问/收藏当作付费或市场验证。最后更新：2026-10-12。

## 1. 先验证哪两种任务
- A（优先，20人）：讲义/PDF -> **MP4 视频 + 逐行高亮 + 大字幕** 的创作者：老师、知识创作者、企业培训人员。明确要求最近1个月做过至少1份类似材料，并能说出原工作流/耗时。
- B（探索，10人）：经常阅读 PDF，希望边看边听的人。**不要称当前产品为在线互动阅读器**；当前是 PDF -> 视频/音频导出，交互点读还不存在。
- 只接受有权使用且非敏感的**文本型 PDF**。不要要求用户传课题组机密、客户财报、个人信息。

## 3. 两种获客实验
**路线 O（Outbound，判断需求）**：查有最近真实任务的人 -> 精准回复/许可私信 -> 问最近一次制作过程 -> 同意试用 -> 通过人工本地生成样片 -> 用户确认质量 -> 在可合法交付且明确价格条件下看真实付款。

**路线 I（Inbound，判断自然分发）**：发布自己的实际 PDF -> 视频效果，内容围绕问题而非功能堆砌 -> 在允许的位置说明开源地址/试用关键词 -> 分清有效询问、试用、付款。自然到来的真实客户单独打标签。

## 4. 14 天安排（只做可控、低成本动作）
D1 检查最终包许可、源码版本对应、Windows 干净机安装，准备可授权的60-90秒真实样片。
D2 从来源中人工筛选30个可能相关的公开讨论（**不是30名已验证客户**），阅读最新互动并手动核实能否联系到符合条件的人；记录场景与原链接。
D3-D4 个性化触达共10个；发布1条真实效果视频；不得群发硬广。
D5-D6 争取完成3个真实场景访谈、2次实际试用；发布1篇技术复盘到允许自荐的社区。
D7 汇总初步失败原因，优先修最频繁的问题；**不得因几条没回复就认定没有市场**。
D8-D10 完成累计20 A + 10 B 目标触达；补足试用。
D11-D12 对已完成真实体验且满意的陌生用户展示明确的真实报价（仅在付费分发/服务条款符合要求后）。
D13 询问下次会在什么真实任务再次使用；获得许可才发送一次跟进。
D14 按下方判定，决定继续A、发展B、改包装或停投入。

## 5. 关键漏斗与判定（内部试验阈值，不是行业标准）
1. **合格触达**：有公开表达的具体任务、且身份与当前能力相符；不是只点赞的人。目标 20A/10B。
2. **有效回复**：明确回答最近一次需求、处理频次或具体异议；“支持”“好棒”不算。30次触达若有效回复 <3，先排查渠道和话术。
3. **真实试用**：本人用自己的已授权 PDF 完成一次流程；只看演示不算。
4. **有效体验**：至少一个视频/音频成功播放，朗读顺序、字幕和高亮可接受。≥5次试用多数失败，先修交付。
5. **真实付费**：无关系客户实际支付、款项到账；“愿意买”“愿意支持”不算。≥6次成功试用且0付费，要区别价格、需求强度、替代方案和交付信任。
6. **复用信号**：可以说出下一次使用任务/日期，或者再给第二份材料；收藏不等于复用。
7. **推进信号**：同一细分场景出现≥2笔独立付费，优先扩大同场景再验证；还不足以称为PMF。

按人群分开计算：有效回复率 = 有效回复人数/合格触达人数；有效体验率 = 完成有效任务人数/真实试用人数；付费转化 = 真实付费人数/完成有效体验人数。记录每条数据的日期、来源与原话；不交叉混算两个场景。

## 7. 可直接复制的沟通顺序
- 第一句：你最近一次把讲义/文档变成视频是在什么时候？具体哪一步最费时？
- 获得允许后：我做了一个保留原PDF、朗读同步逐行高亮、导出MP4的小工具，目前只在部分文本型PDF验证。你愿意用一份不含隐私、自己有权使用的PDF试一次吗？
- 试用后：这段是否达到你下次实际制作视频时的最低要求？如果不行，最致命的一个问题是什么？
- 付费时：源码可以自己免费部署；便携版计划6元用于省配置、支持作者，目前仍在做发布核验。不会向你承诺未实现的功能。
